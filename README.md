# JinGleya Serif Webfonts

WOFF2 files and a specimen page for **JinGleya Serif**, pairing Alegreya
proportional serif Latin with Tsanger JinKai 04 Chinese glyphs. The family has
Light, Regular, and Bold weights with matching italic styles. In italic styles,
the Latin outlines are genuinely italic and the CJK glyphs remain upright.

[View the specimen](https://hanlhe.github.io/JinGleya-Serif-Webfonts/).

## Use

```html
<link rel="stylesheet" href="https://hanlhe.github.io/JinGleya-Serif-Webfonts/JinGleyaSerif.css">
```

```css
body {
  font-family: "JinGleya Serif", serif;
  font-weight: 400; /* 300 Light, 400 Regular, 700 Bold */
  font-style: normal; /* set italic for the corresponding italic face */
}
```

Alegreya's SIL Open Font License 1.1 text is included in `OFL-Alegreya.txt`.
The merged webfont family is for personal, noncommercial use under Tsanger
